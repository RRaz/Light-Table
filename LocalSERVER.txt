Serve a container locally to check it before uploading.

1) In a shell, go to the containers folder of the project:

    cd "C:\Users\photo\projects\light-table\containers"

2) Start a simple static server:

    python -m http.server 8000

    Ctrl+C stops it.

3) In a browser, open the gallery you want:

    http://localhost:8000/<name>/light-table/

    For example, the colour sample:
    http://localhost:8000/colours/light-table/

The address is always <container>/light-table/index.html, the same shape as on the
live site, so a page that works here works when uploaded.
